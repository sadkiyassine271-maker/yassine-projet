Progression des Exercices

Exercice 1

Créer un dépôt GitHub

Accédez à github.com et créez un nouveau dépôt public ou privé.

Exercice 2

Initialiser Git localement

Créer un dossier de projet et lancer l'initialisation du dépôt avec Git.

Exercice 3

Configurer Git

Définir le nom d'utilisateur et l'email professionnel au format requis.

Exercice 4

Créer les fichiers

Créer les fichiers index.html, style.css, script.js et le fichier test secret.txt.

Exercice 5

Configurer .gitignore

Exclure le fichier confidentiel secret.txt en le renseignant dans le .gitignore.

Exercice 6

Premier commit

Ajouter les fichiers du projet en staging et effectuer le premier commit descriptif.

Exercice 7

Créer une branche

Créer une branche de test nommée iffiag-exp et basculer sur celle-ci.

Exercice 8

Modifier & Commit

Faire des modifications de code dans la branche de test et faire un commit.

Exercice 9

Fusionner les branches

Revenir sur master et fusionner les modifications de la branche iffiag-exp.

Exercice 10

Pousser vers GitHub

Lier le dépôt local avec l'URL distante et pousser les modifications sur master.

Exercice 11

Déployer sur Netlify

Se connecter sur Netlify et lier le dépôt GitHub pour lancer le premier déploiement.

Exercice 12

Vérifier l'URL en ligne

Visiter l'URL fournie par Netlify pour valider le bon fonctionnement du site.

Exercice 13

Tester le CI/CD

Modifier un fichier, pousser sur GitHub et valider la mise à jour automatique Netlify.

Exercice 14

Créer le README.md

Ajouter le lien Netlify dans un fichier README.md, faire le commit et pousser.
